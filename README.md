# 🌱 Green World – Plants & Seeds E-Commerce Website

Green World is a front-end e-commerce website developed using **HTML, CSS, and JavaScript**.  
This project simulates a real online shopping experience for plants and seeds with essential e-commerce features.

## ✨ Features

- 🔐 Login & Signup functionality using browser localStorage  
- 🛒 Add to Cart feature  
- ➕➖ Quantity increase and decrease in cart  
- ❌ Remove items from cart  
- 💰 Automatic total price calculation  
- ✅ Checkout flow with success page  
- 🔍 Search filter for products  
- 📱 Responsive navigation bar  
- 🌿 Clean UI with nature-themed design  

---

## 🛠️ Tech Stack

- **HTML** – Structure of the website  
- **CSS** – Styling and responsive layout  
- **JavaScript** – Logic for cart, login, search, and checkout  
- **GitHub Pages** – Live deployment
